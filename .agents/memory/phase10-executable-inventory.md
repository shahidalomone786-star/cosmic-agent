---
name: Phase 10 executable inventory
description: How Ruflo source declarations become countable executable tools without importing unsafe authority.
---

Only count a source tool as executable after it has one canonical registry definition, enabled state, schema and permission enforcement, bounded resource limits, a real server-owned execution path, and audit coverage. Keep unsupported source capabilities as explicit disabled provenance records.

**Why:** The original Ruflo inventory is broader than the security and infrastructure boundary available in this project; counting metadata or silent fallbacks would overstate integration and weaken isolation.

**How to apply:** When extending the Ruflo catalog, verify the measured enabled registry count and focused execution tests together. Preserve Phase 9 identifiers as canonical duplicates instead of registering parallel definitions.
